# LARP Wallet

A fictional, local-only wallet interface for personal role-play/testing.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your GitHub repository (beside `README.md`).
2. In Settings → Pages, choose Deploy from a branch, `main`, and `/(root)`.
3. Wait for the Pages deployment to finish.

The app stores its settings and transactions in the browser's local storage. It does not connect to banks or payment networks and cannot send real money.
